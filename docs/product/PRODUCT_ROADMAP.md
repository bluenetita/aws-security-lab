## Decisions to settle before implementation

The [proposed ADR list](../decisions.md) covers modular boundaries, imported-alert provenance, Wazuh APIs, replay/publication, quality policy, correlation identity, private access, persistent storage, and licensing. Required owners and approval records remain open. M4 establishes source identity and initial source-state semantics. Before live M5, establish preliminary access/threat and retention/recovery requirements. Before affected M6 implementation, resolve applicable ownership, licensing, and provenance. Product MVP controls and persistent storage design are M8 gates. PostgreSQL remains only a storage candidate.

**Recommended next action:** M3 baseline verification with an attributable run record for the current checkout, followed by M4 contract decisions. Obtain separate authorization before executing tests requiring dependencies or infrastructure, staging, manifest regeneration, implementation, or deployment.
